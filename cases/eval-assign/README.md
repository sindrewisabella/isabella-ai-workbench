## 原来怎么工作

通过筛选后，要逐人打开投递、选择评估人，再补推荐理由。

## 现在怎样分工

**我负责：** 确定通过名单、准确投递和评估人，不把分配流程当作筛选标准。

**AI 负责：** 核对岗位与身份，按已确定的名单填写评估人和推荐理由，再检查记录。

## 做到了什么

已有 Skill 和历史分配回读线索；公开页演示虚构任务，不创建真实评估。

**当前状态：** 流程与工具
