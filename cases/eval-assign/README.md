# 指定评估人批量分配

[展示入口](demo.html) · [输入与输出](GUIDE.md) · [结构化资料](case.json) · [流程图](flow.mmd)

## 为什么做

将已确定的人选、投递、评估人和推荐理由准确连接。

## 解决什么问题

将已确定的人选、投递、评估人和推荐理由准确连接。

## 原来怎么工作

通过筛选后，要逐人打开投递、选择评估人，再补推荐理由。

## 现在我做什么

确定通过名单、准确投递和评估人，不把分配流程当作筛选标准。

## 现在 AI 做什么

核对岗位与身份，按已确定的名单填写评估人和推荐理由，再检查记录。

## 实际完成范围

已有 Skill 和历史分配回读线索；公开页演示虚构任务，不创建真实评估。

## 怎样复用

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
