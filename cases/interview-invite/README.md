## 原来怎么工作

在招聘系统里核对人选、时间和面试官，再逐项安排正式邀请。

## 现在怎样分工

**我负责：** 给出面试安排，处理冲突和例外，决定是否发送正式通知。

**AI 负责：** 协助核对投递、重复邀约和忙闲，创建安排后检查通知记录。
