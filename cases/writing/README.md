## 原来怎么工作

AI 草稿常见结论不清、原始片段堆叠，仍要花时间重写。

## 现在怎样分工

**我负责：** 确定要让谁理解什么，核对事实、取舍与自己的表达。

**AI 负责：** 按结构、证据和阅读顺序整理草稿，指出空泛结论并协助重写。

## 做到了什么

留存多项写作与表达 Skill。公开展示虚构输入和改写示例，不公开他人的内部反馈或个人材料。
