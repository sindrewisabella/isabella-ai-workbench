# 薪酬工具

[公开案例](https://isabella-ai-workbench.xieyongshi.chatgpt.site/case.html?id=salary) · [本地示例](demo.html) · [复用说明](GUIDE.md)

## 为什么做、解决什么问题

薪酬材料形式不一，月份与口径容易混淆，多版方案反复调整。

减少从材料到可比较方案的重复整理，让每一笔数据可以核对。

## 原来怎么工作

手动抄录材料里的金额、核对月份，再反复修改表格，比较不同方案。

## 现在怎样分工

**我负责：** 确定比较区间和薪酬口径，复核每一笔材料与日期，判断方案是否合适。

**AI 负责：** 协助搭建流水整理、日期修改与方案比较界面。真实截图/视频识别仍待服务验收。

## 做到了什么

公开示例可以修改流水月份与金额、比较两版方案和导出结果。原工具已有计算、档案与版本代码；截图／视频识别及 Atoms 正式部署还没有验收。

**当前状态：** 可试用示例

## 怎样复用

替换材料、日期和方案参数，先统一税前现金等比较口径，再核对结果；真实截图／视频识别要等 Atoms 版本验收。
