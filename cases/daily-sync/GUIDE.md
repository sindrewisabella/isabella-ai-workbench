# 个人日报定向归档同步：具体怎样使用

## 示例输入

范围：只归档个人 10-18 日报。
源记录 DEMO-DAY-01，目标已有同编号记录。
DEMO-DAY-02 为其他人的日报。

## 处理方式

按本人和日期读取 → 检查重复 → 定向归档 → 回读。

## 示例输出

归档核对
DEMO-DAY-01：已有记录，跳过新增。
DEMO-DAY-02：不属当前个人范围，排除。
新增 0；已有 1；范围外 1。

## 实际完成范围

已有同步脚本，源表与定时状态本次未重验。公开说明不读取个人日报原文。

## 换一个任务

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
