# 个人日报定向归档同步

[展示入口](demo.html) · [输入与输出](GUIDE.md) · [结构化资料](case.json) · [流程图](flow.mmd)

## 为什么做

把个人提交记录归集到固定台账，保留数据来源。

## 解决什么问题

把个人提交记录归集到固定台账，保留数据来源。

## 原来怎么工作

自己填过的日报还要按日期整理到固定台账。

## 现在我做什么

确定本人记录的来源、日期和归档位置。

## 现在 AI 做什么

按来源和日期核对已有记录，进行定向同步，避免重复归档。

## 实际完成范围

已有同步脚本，源表与定时状态本次未重验。公开说明不读取个人日报原文。

## 怎样复用

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
