## 原来怎么工作

候选人通过消息散发材料，延期和提交时间还要人工登记。

## 现在怎样分工

**我负责：** 确定材料要求、截止时间、延期规则和回收口径。

**AI 负责：** 协助做提交表单、延期记录和回执，并把信息接到管理端。

## 做到了什么
