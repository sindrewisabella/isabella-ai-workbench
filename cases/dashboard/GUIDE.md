# 全栈招聘数据看板：具体怎样使用

## 示例输入

全栈岗位，2026-09-21 历史脱敏快照。
选择统计周期：2026-07-01 至 2026-09-21。
使用日期筛选、阶段明细和面试官结果筛选，不连接飞书。

## 处理方式

选择日期 → 查看漏斗 → 点击阶段查看明细 → 对照渠道与目标 → 筛选面试官和结果。

## 示例输出

该快照和日期范围内：
简历入库 5763；简历评估 988；评估通过 322；技术一面 48；技术二面 17；技术终面 10；HR面 5；已入职 3。
指定面试官口径统计 75 场面试，通过 44%、不通过 38.7%、待定 17.3%。
这些是历史过程统计，阶段可能重叠，不将相邻阶段比值当作严格同批转化率；不代表工具带来的招聘增量。

## 实际完成范围

已有全栈招聘看板原版界面、数据接入、周期筛选、阶段明细、目标完成度和面试官进展。首版落地可追溯到 2026-07-23 的仓库提交，不将后续修改计入首版周期。公开版使用 2026-09-21 的历史脱敏快照；招聘人数不作为工具提效或录用贡献。

## 换一个任务

先为各指标写明来源、统计区间和去重方法，再接入新岗位；阶段人数不能直接当作转化率。
