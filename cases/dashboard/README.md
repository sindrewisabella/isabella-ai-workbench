# 招聘看板

[公开案例](https://isabella-ai-workbench.xieyongshi.chatgpt.site/case.html?id=dashboard) · [本地示例](demo.html) · [复用说明](GUIDE.md)

## 为什么做、解决什么问题

不同岗位进度分散，指标口径易混淆。

统一查看漏斗、待处理事项与推进情况。

## 原来怎么工作

分别打开不同岗位的表格，再自己汇总每个阶段有多少人、谁需要跟进。

## 现在怎样分工

**我负责：** 确定指标怎么算，判断卡点原因，决定需要采取的动作。

**AI 负责：** 协助汇总数据、绘制图表和切换岗位，按统一口径展示进度。

## 做到了什么

在已有开源基础上改造了多岗位查看与刷新。这里可以按岗位看阶段人数和待跟进事项；是否让实际决策更快，还没有可核实的数据。

**当前状态：** 可试用示例

## 怎样复用

先为各指标写明来源、统计区间和去重方法，再接入新岗位；阶段人数不能直接当作转化率。
