# 简历评估与校准

[公开案例](https://isabella-ai-workbench.xieyongshi.chatgpt.site/case.html?id=evaluation) · [本地示例](demo.html) · [复用说明](GUIDE.md)

## 为什么做、解决什么问题

经理判断难以复制，简单关键词匹配又不足以支持判断。

让 AI 建议有原文依据，缺口可见，分歧可复核。

## 原来怎么工作

逐份读简历，再按自己对岗位的理解写推荐理由，依据和缺口不容易复核。

## 现在怎样分工

**我负责：** 明确岗位标准，对照原文复核建议，处理分歧并修正规则。

**AI 负责：** 提取原文证据、指出缺口并给出建议，帮助把误判变成可检查的规则。

## 做到了什么

已经留下评估规则、执行代码和不同版本的样本对照。这里能看原文证据、建议与人工复核；测试是否与经理判断一致，需要注明版本和样本单独检验。

**当前状态：** 可试用示例

## 怎样复用

每个岗位单独确认标准，保留原文和缺口；拿未参与制定标准的样本复核，并记录人工修改的原因。
