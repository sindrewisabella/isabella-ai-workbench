# 批量简历评估：具体怎样使用

## 示例输入

虚构 JD：能独立完成增长工具；脱敏简历：“参与广告报表自动化，使用 Python”，未写个人职责和结果。

## 处理方式

按岗位要求找原文 → 把证据、推断和缺口分开 → 生成人工复核稿。

## 示例输出

证据：参与 Python 报表自动化；待核实：本人负责什么、是否上线、结果如何验证；不直接写“独立主导”。

## 实际完成范围

已经留下评估规则、执行代码和不同版本的样本对照。这里能看原文证据、建议与人工复核；测试是否与经理判断一致，需要注明版本和样本单独检验。

## 换一个任务

每个岗位单独确认标准，保留原文和缺口；拿未参与制定标准的样本复核，并记录人工修改的原因。
