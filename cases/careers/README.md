# 公司招聘官网

[公开案例](https://isabella-ai-workbench.xieyongshi.chatgpt.site/case.html?id=careers) · [本地示例](demo.html) · [复用说明](GUIDE.md)

## 为什么做、解决什么问题

希望把公司与岗位展示、岗位筛选和投递入口连接起来。

让外部候选人更容易理解岗位并完成投递。

## 原来怎么工作

通过分散链接介绍公司和岗位，候选人还需要再次确认从哪里投递。

## 现在怎样分工

**我负责：** 确认岗位信息与对外口径，决定投递流程和实际接入范围。

**AI 负责：** 协助开发岗位展示、筛选、详情和投递入口，连接完整浏览路径。

## 做到了什么

已有公司与岗位展示页面，以及模拟和真实投递接口代码。这里可以走完模拟投递；生产招聘系统是否完整接通，目前还没有核实。

**当前状态：** 可试用示例

## 怎样复用

替换公司和岗位内容，明确投递方式。公开示例不接公司招聘系统，真实接入需另外验收。
