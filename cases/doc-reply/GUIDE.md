# 飞书文档评论自动回复：具体怎样使用

## 示例输入

文档定义：“新增人选按投递编号去重。”
指定评论：“同一个人投两个岗位，算几个？”
要求：先生成回复草稿。

## 处理方式

读取评论与正文定义 → 核对口径 → 生成有依据的回复

## 示例输出

回复草稿
本段按投递编号统计。同一个人投递两个岗位，如果对应两个不同投递编号，计为 2 条投递；不等于 2 名不同的人。

依据：正文中的统计定义。
发布状态：未发布。

## 实际完成范围

Skill 与 worker 代码留存；当前服务状态未重验。公开流程不监听或回复真实文档。

## 换一个任务

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
