# 双城座位图

[公开案例](https://isabella-ai-workbench.xieyongshi.chatgpt.site/case.html?id=seats) · [本地示例](demo.html) · [复用说明](GUIDE.md)

## 为什么做、解决什么问题

人员和工位分散在两座城市，布局、待安置和离职信息需要同步。

让人员位置和空位能被直观看到并维护。

## 原来怎么工作

对照人员名单和座位信息，手动查找两座城市的空位和待安置人员。

## 现在怎样分工

**我负责：** 确认人员和座位的实际情况，决定搬迁、分配和信息可见范围。

**AI 负责：** 协助开发城市切换、位置维护与人员同步，让变化可见。

## 做到了什么

已经做出两座城市的座位页面和人员同步代码。这里可以切换城市、分配和释放虚构工位；公司系统的实际同步与使用结果还需要另行核实。

**当前状态：** 可试用示例

## 怎样复用

替换城市、工位布局和人员来源，确认可见范围，再验证调位与空位更新。
