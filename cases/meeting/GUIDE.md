# 会议记录分析与行动项提炼：具体怎样使用

## 示例输入

虚构会议片段：
A：“周三补指标定义。”
B：“收到后我复核。”
另有建议：“可以考虑邮件提醒。”
会议未决定是否做提醒。

## 处理方式

区分决定与建议 → 提取负责人和时间 → 留下未定项

## 示例输出

会议整理
已定事项：先补齐指标定义。
待办 1：A / 周三 / 补定义。
待办 2：B / 收到定义后 / 复核。
未定事项：是否增加邮件提醒。

不把建议写成决定，也不替 B 编造截止日。

## 实际完成范围

已有 Skill 与迭代记录。历史反馈提过初稿仍需人工修改；没有用生成一份纪要来证明节省时间。
