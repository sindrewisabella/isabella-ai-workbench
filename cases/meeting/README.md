## 原来怎么工作

会议记录很长，整理后仍需要反复修改，才能说清各方判断和下一步。

## 现在怎样分工

**我负责：** 判断哪些已经决定、哪些只是建议，核对重要原话。

**AI 负责：** 协助提炼诉求、结论、行动项和未解决的问题，按反馈修改结构。

## 做到了什么

已有 Skill 与迭代记录。历史反馈提过初稿仍需人工修改；没有用生成一份纪要来证明节省时间。

**当前状态：** 流程与工具

## 怎样复用

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
