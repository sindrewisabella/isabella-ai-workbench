## 原来怎么工作

网页脚本的操作方式无法直接套到 Mac 客户端。

## 现在怎样分工

**我负责：** 确定要操作的客户端、岗位与本次范围，处理页面不一致。

**AI 负责：** 通过桌面适配层核对状态、分批执行与保留结果。

## 做到了什么

桌面 CLI 已开源，离线检查通过；不把模拟测试当作当前客户端真实验收。桌面简历写入仍被阻断。

**当前状态：** 试验与方法

## 怎样复用

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
