## 为什么做

展示网页之外的客户端适配及状态检查。

## 解决什么问题

展示网页之外的客户端适配及状态检查。

## 原来怎么工作

网页脚本的操作方式无法直接套到 Mac 客户端。

## 现在我做什么

确定要操作的客户端、岗位与本次范围，处理页面不一致。

## 现在 AI 做什么

通过桌面适配层核对状态、分批执行与保留结果。

## 实际完成范围

桌面 CLI 已开源，离线检查通过；不把模拟测试当作当前客户端真实验收。桌面简历写入仍被阻断。

## 怎样复用

先准备对应输入并明确操作范围；替换岗位、使用者或目标记录后，重新核对身份、权限和完成结果。
