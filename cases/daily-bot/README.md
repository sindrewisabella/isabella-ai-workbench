## 原来怎么工作

每天要记日报和明日待办，第二天还要重新整理提醒。

## 现在怎样分工

**我负责：** 确定填报字段、提醒时间和接收位置，判断待办优先级。

**AI 负责：** 协助生成填报卡、收集记录，并把待办整理成次日提醒。
