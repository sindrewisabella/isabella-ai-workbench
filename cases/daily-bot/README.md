## 原来怎么工作

## 现在我做什么

确定填报字段、提醒时间和接收位置，判断待办优先级。

## 现在 AI 做什么

协助生成填报卡、收集记录，并把待办整理成次日提醒。

## 实际完成范围

Skill、脚本和配置留存；当前定时服务未在本次重验。公开页仅演示填报到提醒的流程。
