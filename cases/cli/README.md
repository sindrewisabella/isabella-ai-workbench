# 招聘 CLI 系列

[展示入口](demo.html) · [输入与输出](GUIDE.md) · [结构化资料](case.json) · [流程图](flow.mmd)

## 为什么做

渠道上的搜索、读资料、联系与回收包含大量重复操作。

## 解决什么问题

让同一流程可以换岗、核对身份、去重、记录回执并在异常时停止。

## 原来怎么工作

逐个人工查看、点击招呼、回到会话索要并接收简历。

## 现在我做什么

我确认岗位、找人条件和操作范围；处理候选人沟通，检查结果。

## 现在 AI 做什么

AI 读取资料、按既定规则分批执行，去重并留下回执。

## 实际完成范围

10 月最高招呼日的账号统计与本次页面演示在作品页分别展示；账号总量不全部归为 CLI 成果。

## 怎样复用

替换岗位配置、筛选条件、招呼语与执行范围。先检查登录和页面状态，每批核对回执；没有“永不封号”的保证。

## 贡献与来源

沿用同事提供的基础方案与已有工具能力，我明确岗位标准、多岗位复用和核对要求，推动适配与验证；AI 协助代码整理、重复执行和结果汇总。

既有公开代码与许可证见 [source/](source/) 及 [SOURCE.md](SOURCE.md)。
