## What · 做什么

按规则整理材料、运行可检查的项目，输出独立报告并记录首测或复测。

## Why · 为什么用

收到笔试后，要分别打开文档、页面和代码，反复确认哪里需要返修。

## How · 怎么使用

1. 读取文档与代码
2. 按要求验收
3. 给出返修项
4. 复测并回传结果

## 达到什么效果

已有验收 Skill 和历史报告线索。公开展示流程；没有公开真实人选材料，也不声称所有历史验收结论正确。
