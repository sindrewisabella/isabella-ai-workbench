# 候选人分歧讨论

原条目：`talent-discussion-post` · [关联案例](../../cases/writing/) · [复用说明](GUIDE.md)

## What · 做什么

按结构、证据和阅读顺序整理草稿，指出空泛结论并协助重写。

## Why · 为什么用

AI 草稿常见结论不清、原始片段堆叠，仍要花时间重写。

## How · 怎么使用

1. 明确读者与目的
2. 检查事实与结构
3. 重写表达
4. 本人核对与定稿

## 达到什么效果

留存多项写作与表达 Skill。公开展示虚构输入和改写示例，不公开他人的内部反馈或个人材料。
