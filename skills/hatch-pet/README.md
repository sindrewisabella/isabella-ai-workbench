# 动画宠物创作与打包

原条目：`hatch-pet` · [关联案例](../../cases/pets/) · [复用说明](GUIDE.md)

## What · 做什么

协助生成图像、整理动画状态、检查并打包产物。

## Why · 为什么用

想把一个视觉形象变成有动作的桌面小伙伴，需要反复检查形象与动画是否一致。

## How · 怎么使用

1. 确认形象与素材来源
2. 生成动作草稿
3. 检查一致性与边缘
4. 验证并打包

## 达到什么效果

有生成请求、Skill 和本地宠物目录；没有逐一复查所有动画包。这里仅说明制作流程，不发布未核实来源的原动画素材。
