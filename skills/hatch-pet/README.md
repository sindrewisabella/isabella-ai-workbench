# 动画宠物创作与打包

## What

协助生成图像、整理动画状态、检查并打包产物。

## Why

想把一个视觉形象变成有动作的桌面小伙伴，需要反复检查形象与动画是否一致。

## How

1. 确认形象与素材来源
2. 生成动作草稿
3. 检查一致性与边缘
4. 验证并打包

## 实际效果与范围

有生成请求、Skill 和本地宠物目录；没有逐一复查所有动画包。这里仅说明制作流程，不发布未核实来源的原动画素材。
