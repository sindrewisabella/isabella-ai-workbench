# 面试评价

原条目：`interview-evaluator` · [关联案例](../../cases/interview-evaluator/) · [复用说明](GUIDE.md)

## What · 做什么

提取原文证据，整理岗位匹配、缺口与后续追问。

## Why · 为什么用

面试结束后，要把长记录结合岗位要求整理成有依据的评价。

## How · 怎么使用

1. 输入岗位与记录
2. 提取原文依据
3. 整理评价和追问
4. 人工复核结论
