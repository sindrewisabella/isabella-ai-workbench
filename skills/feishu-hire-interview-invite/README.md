# 正式面试邀约

原条目：`feishu-hire-interview-invite` · [关联案例](../../cases/interview-invite/) · [复用说明](GUIDE.md)

## What · 做什么

协助核对投递、重复邀约和忙闲，创建安排后检查通知记录。

## Why · 为什么用

在招聘系统里核对人选、时间和面试官，再逐项安排正式邀请。

## How · 怎么使用

1. 确认人选与时间
2. 核对投递和重复记录
3. 创建面试安排
4. 检查邀请回执

## 达到什么效果

Skill 与历史邀请记录存在。公开说明和示例不发送邮件、短信或真实邀请。
