# 文档评论回复

原条目：`feishu-doc-comment-autoreply` · [关联案例](../../cases/doc-reply/) · [复用说明](GUIDE.md)

## What · 做什么

读取新增评论，检查是否已处理，整理回复并记录回执和失败原因。

## Why · 为什么用

同事在文档里提问题后，要反复查看新评论，再逐条回复和排查漏回。

## How · 怎么使用

1. 读取范围内评论
2. 检查重复处理
3. 整理回复
4. 回读并记录异常
