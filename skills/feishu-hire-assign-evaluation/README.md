# 指定评估人分配

原条目：`feishu-hire-assign-evaluation` · [关联案例](../../cases/eval-assign/) · [复用说明](GUIDE.md)

## What · 做什么

核对岗位与身份，按已确定的名单填写评估人和推荐理由，再检查记录。

## Why · 为什么用

通过筛选后，要逐人打开投递、选择评估人，再补推荐理由。

## How · 怎么使用

1. 确认名单与评估人
2. 核对投递身份
3. 安排评估
4. 回读结果

## 达到什么效果

已有 Skill 和历史分配回读线索；公开页演示虚构任务，不创建真实评估。
