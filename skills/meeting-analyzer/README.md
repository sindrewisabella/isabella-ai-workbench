# 会议记录分析

原条目：`meeting-analyzer` · [关联案例](../../cases/meeting/) · [复用说明](GUIDE.md)

## What · 做什么

协助提炼诉求、结论、行动项和未解决的问题，按反馈修改结构。

## Why · 为什么用

会议记录很长，整理后仍需要反复修改，才能说清各方判断和下一步。

## How · 怎么使用

1. 读取原始记录
2. 区分决定与建议
3. 整理负责人和下一步
4. 人工复核与修改

## 达到什么效果

已有 Skill 与迭代记录。历史反馈提过初稿仍需人工修改；没有用生成一份纪要来证明节省时间。
