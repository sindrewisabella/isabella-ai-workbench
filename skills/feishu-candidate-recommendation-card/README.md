# 候选人推荐卡

原条目：`feishu-candidate-recommendation-card` · [关联案例](../../cases/recommendation/) · [复用说明](GUIDE.md)

## What · 做什么

把证据、待核实项和材料入口整理成固定卡片，协助排版与核对。

## Why · 为什么用

推荐人选时，简历、理由、待核实问题和协作入口分散在不同地方。

## How · 怎么使用

1. 核对人选与岗位
2. 提取证据
3. 生成卡片预览
4. 人工复核后使用

## 达到什么效果
