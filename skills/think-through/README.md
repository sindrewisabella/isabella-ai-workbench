# 思考路径与归因

## What

通过追问帮助发现目标、差距和假设，最后把行动收敛成可以检查的结果。

## Why

面对模糊任务时，容易直接找方案，还没说清要改变什么。

## How

1. 确定谁的问题
2. 描述期望结果
3. 检查判断与证据
4. 收敛下一步与交付物
