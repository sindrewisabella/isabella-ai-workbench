原条目：`boss-desktop` · [关联案例](../../cases/boss-desktop/) · [复用说明](GUIDE.md)

## What · 做什么

通过桌面适配层核对状态、分批执行与保留结果。

## Why · 为什么用

网页脚本的操作方式无法直接套到 Mac 客户端。

## How · 怎么使用

1. 确认客户端与岗位
2. 检查页面状态
3. 按范围执行
4. 核对结果并停止异常

## 达到什么效果

桌面 CLI 已开源，离线检查通过；不把模拟测试当作当前客户端真实验收。桌面简历写入仍被阻断。
