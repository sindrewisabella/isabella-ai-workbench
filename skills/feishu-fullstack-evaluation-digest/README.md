# 全栈待评估汇总

原条目：`feishu-fullstack-evaluation-digest` · [关联案例](../../cases/progress-cards/) · [复用说明](GUIDE.md)

## What · 做什么

按范围汇总数据，生成岗位卡片，并对照记录检查遗漏与重复。

## Why · 为什么用

更新招聘进展时，要找出待处理人选、负责人和下一步，再重新整理消息。

## How · 怎么使用

1. 读取当前岗位进展
2. 核对负责人和下一步
3. 生成卡片
4. 核对展示与发送记录

## 达到什么效果

多个岗位卡片、Skill 和历史发送记录留存。按一个系列展示，不把不同岗位版本算成不同产品。
