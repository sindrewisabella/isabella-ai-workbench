# 日报填报与次日提醒

## What

协助生成填报卡、收集记录，并把待办整理成次日提醒。

## Why

每天要记日报和明日待办，第二天还要重新整理提醒。

## How

1. 填写当日记录
2. 保存明日待办
3. 整理提醒
4. 人工调整安排

## 实际效果与范围

Skill、脚本和配置留存；当前定时服务未在本次重验。公开页仅演示填报到提醒的流程。
