# 日报填报与次日提醒

原条目：`daily-report-bot` · [关联案例](../../cases/daily-bot/) · [复用说明](GUIDE.md)

## What · 做什么

协助生成填报卡、收集记录，并把待办整理成次日提醒。

## Why · 为什么用

每天要记日报和明日待办，第二天还要重新整理提醒。

## How · 怎么使用

1. 填写当日记录
2. 保存明日待办
3. 整理提醒
4. 人工调整安排

## 达到什么效果

Skill、脚本和配置留存；当前定时服务未在本次重验。公开页仅演示填报到提醒的流程。
