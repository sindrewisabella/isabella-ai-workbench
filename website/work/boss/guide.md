# BOSS 多岗位框架

把打招呼、求简历和附件接收整理为按岗位配置的流程。

## 产出形式
CLI · 使用说明

## 版本与组成
- 浏览器框架
- Mac 桌面端适配

## 使用前需要
- 岗位与筛选范围
- 已登录的 BOSS 账号
- 本次动作与数量

## 操作流程
1. 确认账号、岗位与可用权益
2. 读取候选人并核验身份
3. 分批执行已授权动作
4. 按回执对账，异常时停止

## 产出
- 岗位配置
- 批次记录
- 操作回执与去重记录
