# 招聘数据看板

按岗位查看招聘阶段、待跟进事项与历史漏斗。

## 产出形式
网页 · 交互展示

## 版本与组成
- 全栈看板
- 多岗位迁移版

## 使用前需要
- 招聘数据
- 阶段口径
- 岗位配置

## 操作流程
1. 读取各岗位来源
2. 检查身份与数据完整性
3. 按规则汇总状态
4. 查看待跟进与积压

## 产出
- 招聘看板
- 岗位配置
- 刷新与维护说明
