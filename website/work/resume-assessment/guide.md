# 多岗位简历评估

从简历提取依据，按岗位标准整理推荐结论与待补充信息。

## 产出形式
智能体 · 规则说明

## 版本与组成
- 全栈评估多版本
- 运维规则
- 测试规则

## 使用前需要
- 岗位标准
- 简历内容
- 人工复核规则

## 操作流程
1. 提取简历中的原文证据
2. 按对应岗位规则检查
3. 输出结论与缺失信息
4. 人工复核并记录分歧

## 产出
- 评估规则
- 推荐理由
- 复核流程

## 展示与访问条件
岗位标准分别适配；模型输出需要人工复核，计划中的测试不作为已经达成的指标。
